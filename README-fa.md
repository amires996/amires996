* 🧩 مسلط به C# و آشنا با محیط توسعه .NET
* 🌐 کار با HTML، CSS، JavaScript و WordPress
* 🎨 علاقه‌مند به طراحی UI/UX با Figma
* 🐧 علاقه‌مند به Linux، Windows و محیط‌های توسعه
* 📚 یادگیری فناوری‌های جدید از طریق پروژه‌های عملی
* 🎯 تمرکز بر ساخت محصولات کاربردی و پیشرفت مستمر
